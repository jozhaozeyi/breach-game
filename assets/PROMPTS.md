# Generated visual assets

Generated using the built-in image_gen tool. Assets are copied into this directory; originals remain in the generation library. No external stock images are used. The current game uses tactical-operators-v2.png. Older images are retained as historical assets. The environment is drawn from level coordinates in scene-environment.js.
