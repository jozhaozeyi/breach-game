# 零界突入 / BREACH · 纯键盘行动版

用电脑版 Chrome 或 Edge 打开 `index.html`，按 Enter 开始。可离线游玩，无需安装依赖。

## 操作

- WASD：移动；← / →：按住向左 / 右平滑加速旋转，松开后短暂减速停稳，可边移动边转向。
- Q / E：向左 / 右微调瞄准角度，可瞄准任意方向。
- 空格：按住连续发射霰弹，每枪 9 颗弹丸，间隔 0.65 秒；普通士兵命中一枪就倒，重装兵和指挥官保留装甲与生命值。
- R：换弹；SG-8 弹容量 8 发，初始备弹 48 发，换弹 1.8 秒，弹药补给每箱 16 发。
- F：开关附近房门、拾取补给、执行关卡任务、撤离。
- G：朝瞄准方向投掷手雷，0.7 秒后爆炸，每关三枚，不伤自己。墙和掩体会阻挡投掷及爆炸伤害。
- Shift：沿移动方向冲刺；站立时沿瞄准方向冲刺，冷却 2.8 秒。
- V：使用医疗包，1.4 秒恢复 40 生命；开火、受伤会中断。
- P / Esc：暂停或继续；M：切换声音。
- 菜单：方向键切换选项，Enter 或空格确认，也支持 Tab。开始、重试、下一关、返回确认均可只用键盘完成。

鼠标移动与点击不参与移动、瞄准或开火。

## 六个关卡

1. **解救护送 / 城市前哨**：找到蓝色标记的工程师，靠近按 F 解救。他会沿通路跟随你并开启附近房门。带他走到东侧出口，再按 F 撤离；距离太远时停下等待。
2. **定点爆破 / 研发设施**：前往两处金色标记，按 F 后保持不动两秒安装炸药；移动、冲刺、开火、投雷、换弹或受伤会中断。两处完成后启动八秒引爆倒计时，离开红色危险圈；爆炸会伤害附近的人。爆破后从南侧出口撤离。
3. **守点撤离 / 指挥中枢**：先击败指挥官，再回入口按 F 呼叫接应。在绿色圆圈中累计坚守 30 秒，期间有三波增援；离开圆圈会停止累计。接应抵达后靠近入口按 F 完成行动。

4. **军械库拆弹 / 地下军械库**：找到三枚炸弹，靠近按 F 打开面板，按显示顺序输入四个方向键。输错会重新开始当前序列，F 或 Esc 退出面板，WASD 退出并移动；战斗继续，受伤会中断。全部拆除后向东撤离。
5. **补给搬运 / 物流转运站**：靠近蓝色补给箱按 F 搬起，一次一箱，携带时移动稍慢。运回南侧绿色卸货点按 F 交付，交付两箱后撤离。
6. **供电核心**：在中央大厅与四个侧厅之间战斗，用霰弹枪或手雷摧毁三台红色供电装置，并击败守备队长，然后从北侧出口完成六关行动。

每关恢复生命、弹药、两份医疗包和三枚手雷。失败可重试当前关卡；暂停时所有战斗、引爆与防守计时都会停止。

墙、门和家具具有实体碰撞并阻挡子弹。敌人会巡逻、听声警戒、追击并开门。敌人反应与追击速度已放缓，子弹速度降低；普通兵每次命中造成 7 点伤害，重装兵 6 点，指挥官每颗弹丸 8 点，射击间隔也已延长。利用门和掩体换弹。

## 文件

- `index.html` / `style.css`：菜单、操作提示与状态栏。
- `levels.js`：地图、碰撞、寻路。
- `missions.js` / `extra-missions.js`：六种任务、拆弹键盘操作及任务标记。
- `game.js`：键盘输入、战斗、手雷、敌人和流程。
- `render.js`：Canvas 场景、人物和瞄准指示。

单人本地网页游戏，刷新会重置行动进度。旧游戏“联合突围”的备份仍在 `../archives/`。
