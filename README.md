# 零界突入 · 写实 2D 战术行动

用桌面 Chrome 或 Edge 打开 `index.html`，选择干员、主副武器和行动后按 Enter 开始。纯静态网页，可以离线游玩。当前入口为写实风格的 2D 室内横版游戏，使用高分辨率画布、透明人物动画图集，以及单独绘制的枪械、枪口闪光、烟雾、灯光和阴影。背景按关卡实际坐标绘制，不再使用整幅场景照片；办公、档案、医院、仓储、通信、配电、车站等区域有对应布置，家具落在实际地面并避开任务点。36 关任务、干员技能、武器限制、音乐与音效保持可用；所有关卡地面均为连续平地。

人物图集包含友方与敌方各六种姿态：待机、四帧行走与跳跃。行走按实际移动距离播放，带冲刺前倾、呼吸起伏、后坐力、换弹和斜向瞄准。友方为深蓝制服、露脸头盔和浅蓝识别带；敌方为沙色迷彩、黑面罩、重甲和橙色识别带。电脑使用键盘；触屏设备自动开启移动端操作，也可用右上角「触控」手动切换。

## 移动端操作

支持横屏、竖屏、多点触控与屏幕安全区域。左侧摇杆左右移动，上拨跳跃、下拨慢行；右侧按住开火，可以同时移动和射击。按钮提供跳跃、交互、技能、切枪、换弹、手雷/震撼弹、治疗、冲刺，以及平瞄/上瞄/下瞄切换。遇到 F 提示时点「交互」。方向密码与拆弹可以点方向按钮，也可以拨动摇杆输入。暂停、旋转屏幕或切到后台会释放触屏按键，避免持续开火或移动。

竖屏调整视野，游戏地面抬到操作按钮上方；移动端限制超出横向视野的敌人直接射击，并将画布像素比上限设为 1.5。横屏有更宽视野。布局和指针事件已在桌面 Chrome 自动验证，尚未进行实体 iOS/Android 设备测试。

## 二楼与高度变化

36 关都有实际可进入的二楼或夹层楼板，并由楼梯连接下层；前六关分别布置了大厅二楼、档案楼长走廊、车库上层通道、爆破撤离夹层、车站多段夹层和楼上据点。部分目标、守军和补给放在上层。楼板挡住子弹，楼梯可以直接走上走下，移动列车不会被楼梯错误吸附。

电脑按住 S 再按 W/↑ 可以从上层落下；手机将摇杆向下拨住，再点跳跃。落下期间只穿过上层楼板，不穿过一楼地面。按住慢行经过楼梯入口可以选择走下层路线。

## 连续战役与顺序解锁

36 关由一条连续剧情连接，分为「暗线突入、断电之城、追踪与围城、逆流救援、黎明之前」五幕。每关有入场简报、任务中无线电文字和通关结尾；下一关简报会接上上一关的结果。首次从第 1 关开始，完成当前关卡后只解锁下一关。失败与重试不会解锁，已通关关卡可重玩。剧情简报期间战斗暂停，点击「进入行动」或按 Enter 开始。

## 前六关新玩法

前六关使用不同的手工地图。掩体会挡人、挡子弹并被打碎，破坏后移除碰撞；油桶爆炸会伤害附近双方，并能连锁引爆。潜入扫描可关闭或射坏，暴露招来追兵；运输车有移动、射击与半血护卫阶段；爆破有追赶火线和延时轰炸预警；列车使用真实移动平台；据点要求清除守军后留在区域内占领。自动通关测试使用正常生命、弹药、治疗和技能，不代替人工难度评价。

## 操作

| 按键 | 操作 |
| --- | --- |
| A / D、← / → | 左右移动 |
| W、↑ | 跳跃；提前松开可缩短跳跃高度 |
| S + W / ↑ | 从二楼或夹层向下落到下层 |
| 空格、J | 按住开火，自动辅助瞄准面向方向的附近敌人 |
| Q / E | 向斜上 / 斜下瞄准 |
| 1 / 2 | 切换所装备的主武器 / 副武器 |
| C | 释放所选职业技能 |
| F | 操作任务设备、拾取补给、撤离、退出拆弹面板 |
| R | 给当前武器换弹 |
| G | 投掷手雷；活捉任务中改为不致命的震撼弹 |
| V | 使用医疗包，恢复 45 点生命；开火或受伤会中断 |
| Shift | 向面向方向冲刺；负重时不可用 |
| P / Esc | 暂停、继续 |

方向键面板打开时，按显示顺序输入方向键。输错可重试，F 或 Esc 关闭面板。移动使用 A/D，跳跃使用 W/↑，射击使用空格（也保留 J），不再使用原俯视版的转向控制。

角色受重力影响，可以从下方跳过平台，在落下时站到平台上。地面连续，掩体可以跳过或打碎，跳跃也用于登上高处平台。镜头随角色横向滚动；任务栏保持在顶部窄条区域。前六关抵达接应点自动撤离；后续关卡完成任务后需到安全出口按 F 撤离，护送任务必须等待同行人员到达。

## 主副武器与职业

| 装备栏 | 武器 | 弹匣 / 初始备弹 | 特点 |
| --- | --- | --- | --- |
| 主武器 | M870 霰弹枪 | 8 / 48 | 近距离多弹丸 |

初始界面必须各选一把主武器和副武器，手枪与刀二选一。只携带所选两把武器，按 1/2 切换。弹匣和备弹独立保存，切换不会补满弹药。补给箱补充当前枪械；持刀时补充主武器。每关重置生命、已装备武器弹药、三份医疗包和五枚手雷。武器与职业选择保存在本地浏览器。

| 职业 | C 技能 | 效果 | 冷却 |
| --- | --- | --- | --- |
| 突击兵 | 火力强化 | 8 秒内枪械伤害提高 50%，射击间隔缩短 25% | 25 秒 |

技能状态显示在战斗界面；暂停时冻结冷却，每关及重试重置技能。手机可用独立技能按钮，按钮显示剩余冷却。

## 音乐与音效

点击界面或按键后开始播放：菜单使用轻量氛围音乐，行动中增加节奏与低鼓。右上角「音乐」可单独关闭背景音乐，「声音」控制全部声音；两项选择会保存。暂停、离开页面或行动结束时停止背景音乐，继续行动时恢复。枪声和爆炸期间会短暂降低背景音乐音量，并通过动态压缩控制混音峰值。音频由 Web Audio 在本地实时合成，无需网络或额外音频下载。

原俯视版的 JS/CSS 仍在项目中留存，当前 `index.html` 不加载它们。旧的 `breach-game-modern-36.zip` 为改版前备份；室内版离线包为 `breach-game-indoor-36.zip`。

## 验证

项目外 `.qa/action-missions-check.html` 验证新战斗机制与全部关卡加载；`action-route-check.html` 验证真实跳跃、破门和登车；`action-playthrough-check.html` 自动实战通关前六关；`story-progress-check.html` 验证剧情、顺序解锁与结局；`animation-check.html` 验证动作和敌我模型；`loadout-skills-check.html` 验证主副武器与技能。`start-button-check.html` 检查菜单布局及简报进入流程。自动检查不等于人工通关所有战斗的难度测试。
